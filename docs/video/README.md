# 自動操縦の紹介動画の作り方

「自動操縦」を紹介する約 42 秒の動画（1920×1080、キャプション・BGM 付き）を組み立てるスクリプトです。
完成した動画はリポジトリに入れません（`out/` は Git 管理外）。

## 必要なもの

- macOS（キャプションにヒラギノ角ゴシックを使います）
- `ffmpeg` / `ffprobe`（`brew install ffmpeg`）
- Python 3（初回実行時に `docs/video/.venv` を作って Pillow を入れます）
- 自動操縦の画面収録（Chrome のウィンドウを Retina で収録したもの。2750×2046 を前提に切り抜きます）

## 使い方

```bash
docs/video/build.sh ~/Desktop/画面収録.mov
# → docs/video/out/bolt-pilot-autopilot-bgm.mp4（BGM あり）
#    docs/video/out/bolt-pilot-autopilot.mp4（BGM なし）
```

## ファイル

| ファイル | 役割 |
|---|---|
| `build.sh` | 全体の組み立て。切り抜き座標、使う区間、キャプションの表示タイミングもここ |
| `captions.py` | キャプション画像（下部の帯）と、タイトル・しくみ・終わりの画面を生成 |
| `bgm.py` | BGM をその場で合成（既存の曲や音源素材は使わないオリジナル。112 BPM、C–Am–F–G） |

## 構成

1. タイトル（3.5 秒）
2. しくみの図：iPhone カメラ → AI（Jev）→ ブラウザ → BOLT（5.5 秒）
3. 画面収録 + キャプション：開始 → 向き合わせ → 走行（0.5 倍速）→ 引き返し → 停止 → ステータス表示 → くり返し
4. 終わりの画面（4 秒）

## 作り直すときの注意

- **区間の秒数は、2026-11-11 に撮ったサンプル収録に合わせてあります。** 別の収録を使うときは、
  状態表示（判定待ち・向き合わせ中・走行中・引き返し中・停止中）の切り替わる秒数を確認して、
  `build.sh` の `seg` 行を書き換えてください。説明の順番に合わせるため、時系列を入れ替えてつないでいます。
- 収録のウィンドウサイズが違うと切り抜きがずれます。`build.sh` の `crop=` を調整してください。
- 文言を変えるときは `captions.py` の `CAPS` を編集します。
- BGM のドラムは 9 秒以降の小節頭から入り、38 秒で抜けます（`bgm.py` の `DRUMS_IN` / `OUTRO`）。
